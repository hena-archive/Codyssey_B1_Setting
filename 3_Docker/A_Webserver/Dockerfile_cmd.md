# Dockerfile 주요 명령어

| 명령어 | 역할 | 설명 |
|--------|------|------|
| `FROM` | 베이스 이미지 선택 | 새로운 이미지를 만들 때 사용할 기본 이미지를 지정합니다. 모든 Dockerfile은 `FROM`으로 시작합니다. |
| `COPY` | 파일 복사 | 호스트(프로젝트 폴더)의 파일이나 디렉터리를 컨테이너 이미지 내부로 복사합니다. |
| `ADD` | 파일 복사 및 압축 해제 | `COPY`와 비슷하지만, 압축 파일을 자동으로 해제하거나 URL의 파일을 가져오는 기능을 제공합니다. 일반적으로는 `COPY` 사용을 권장합니다. |
| `RUN` | 이미지 빌드 중 명령 실행 | `docker build` 과정에서 명령을 실행하여 이미지에 반영합니다. 예를 들어 패키지 설치나 디렉터리 생성 등에 사용됩니다. |
| `CMD` | 컨테이너 실행 시 기본 명령 지정 | `docker run`으로 컨테이너를 시작할 때 기본적으로 실행할 명령을 지정합니다. |
| `ENTRYPOINT` | 컨테이너 실행 시 항상 실행할 명령 지정 | 컨테이너가 시작될 때 항상 실행되는 명령을 지정합니다. 일반적으로 `CMD`와 함께 사용됩니다. |
| `EXPOSE` | 사용할 포트 문서화 | 컨테이너가 사용할 포트를 명시합니다. 실제 포트 연결은 `docker run -p` 옵션으로 수행합니다. |
| `ENV` | 환경 변수 설정 | 컨테이너 내부에서 사용할 환경 변수를 설정합니다. |
| `WORKDIR` | 작업 디렉터리 설정 | 이후 실행되는 `RUN`, `CMD`, `ENTRYPOINT`, `COPY` 등의 기본 작업 디렉터리를 지정합니다. |
| `USER` | 실행 사용자 변경 | 컨테이너 내부에서 명령을 실행할 사용자를 지정합니다. 기본값은 `root`입니다. |
| `VOLUME` | 볼륨 마운트 위치 지정 | 데이터를 영구적으로 저장하기 위한 볼륨의 마운트 위치를 지정합니다. |
| `HEALTHCHECK` | 컨테이너 상태 확인 | 컨테이너가 정상적으로 동작하는지 주기적으로 검사하는 명령을 정의합니다. |

---

## 실행 시점에 따른 구분

### 이미지 빌드 시 실행

- `FROM`
- `COPY`
- `ADD`
- `RUN`
- `ENV`
- `WORKDIR`
- `USER`
- `VOLUME`
- `EXPOSE`
- `HEALTHCHECK`

위 명령어들은 `docker build` 과정에서 이미지에 설정을 추가하거나 메타데이터를 정의합니다.

### 컨테이너 실행 시 사용

- `CMD`
- `ENTRYPOINT`

이 두 명령어는 `docker run`으로 컨테이너가 시작될 때 실행되는 프로그램을 결정합니다.
